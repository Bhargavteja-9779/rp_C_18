# Deviations from protocol.md (all made 2026-11-22 BEFORE any model was trained or evaluated)
1. Download: California (06) and Colorado (08) failed to download (API timeouts on very large states); excluded. 49 of 51 requests succeeded; 47 states have wells after filtering.
2. Features: sampling depth is missing for 100% of wells in this API output, so it is dropped. Features are latitude, longitude and USGS aquifer code (42% present; "unknown" otherwise).
3. Evaluation units: the protocol's KMeans blocks are not fixed across partitions, which breaks paired tests. PRIMARY evaluation is now leave-one-state-out (state = fixed, independent unit; a state agency runs a campaign in its own state; cold-start setting) with a 25 km buffer; states need >=100 wells and >=15 unsafe wells. SECONDARY: a single KMeans partition (60 blocks, seed 0) as within-region robustness. Everything else (methods, metrics, budgets, tests) is unchanged.
4. Tuning: 8 states drawn at random (seed 0) are used ONLY for tuning (LightGBM random search, 20 trials; kernel bandwidth and shrinkage grids) and never as evaluation units. Their wells may be used as training data for other states.
5. Random-order baseline M0 is the analytic expectation (budget fraction x number of unsafe wells), not simulated.
6. Seeds: 5 LightGBM seeds (0-4), averaged per state before testing.
7. (added after the main runs) Nitrate (second contaminant) could not be downloaded: the API timed out for 47 of 49 states. It is NOT in the paper. Generality evidence is therefore limited to arsenic (>10 and >5 ug/L), two split designs, and a thinned-data check.
8. (added after the main runs) Extra robustness run not in the original protocol, added in response to a review concern about clustered sampling: wells thinned to one per 1 km cell (`as10_thin`). It was run once; no variants were tried and discarded.
9. The As>5 run draws its own 8 tuning states (39 eligible states, not 37), because eligibility depends on the label.
10. Random-vs-blocked comparison (RQ1) uses 3 seeds, not 5, and the pooled random 5-fold is not buffered.
11. (added after the main runs, in response to a review on baseline fairness) The online-refit baseline M7 used a fixed weight of 20 on tested wells that was not tuned. A check with weights 1, 20 and 100 (3 seeds, same states) was run once and is reported regardless of outcome (`results/m7_weight_check.csv`). The best of the three is an upper bound for M7, chosen after seeing results, so it is reported as such and not used as the main M7 number.
12. (added after the main runs) Negative control (labels shuffled within state) and per-method timing were added (`results/extra_checks.json`). Both run once.
13. (added after the main runs, 2026-11-23) Extra experiments, each run once, all reported: kappa sweep (0.5-1000), two heuristic baselines (H1 follow-unsafe-only; H2 greedy spatial spread), a spatial-clustering analysis of unsafe wells, a warm-start design (earliest 50% of a state's wells by sample date are history; campaign on the later 50%), and a regional consistency check (Census regions). Code: `code/src/extra_experiments.py`, `analyze_extra.py`. Reason: reviews 03, 04, 08 and the stakeholder review.
14. (added 2026-11-23) Second contaminant: uranium (USGS Samples API; California and Colorado downloaded for uranium). Chosen BEFORE running experiments on it: thresholds 30 ug/L (US MCL; only 13 states meet the unit-size rule, so 4 tuning states and 9 evaluation states) and 10 ug/L (21 eligible states, 8 tuning). Same methods, tuning budget, statistics. The unit-size rule (>=100 wells, >=15 unsafe) is unchanged. Nitrate remains un-downloaded and is not in the paper.
15. The 'lift' statistic (P(neighbour unsafe | unsafe) / prevalence within r km) was defined when the mechanism analysis was written, before correlating it with enrichment; three radii (2, 5, 20 km) were reported, none dropped.
16. (2026-11-23, round 3, BEFORE running any geology experiment) Geology predictors added from USGS SGMC (state geologic map compilation): generalized lithology class (28 classes) and a coarse geologic age (last token of AGE_MIN; classes with <1% of wells pooled to 'other'), joined by point-in-polygon. Selected by availability and by being transferable across states; no geology feature was tried and dropped. Runs: As>10, As>5, uranium 30 and 10 with `WELL_FEATS=geo`. The tuning states, protocol, methods and statistics are unchanged; hyperparameters are re-tuned on the tuning states because the feature set changed. A geology-informed baseline G0 (rank by lithology-class prevalence in other states' wells) is added.
17. (2026-11-23, round 3) Robustness checks added and run once, all reported: delayed results (batch sizes 10, 50, 200), 30% of wells unavailable, leave-one-region-out. Code: `code/src/robust_checks.py`.
18. (2026-11-23, round 3) California and Colorado arsenic re-downloaded by date windows with `code/download_chunked.py` (the original single-request download timed out); they are NOT merged into the main arsenic results, to keep the evaluated data identical to the pre-registered runs; if merged, a new run would be labelled separately.
19. (2026-11-23, round 3) After the date-window download succeeded, California and Colorado arsenic were added in a SEPARATE run (`results/as10_full`, base predictors, As>10) on a dataset that includes them (`wells_as_full.csv`). The eligible-state list changes, so the tuning states are re-drawn (seed 0, 8 states). It is reported as an extra check, not as a replacement for the main run.
20. (2026-11-23, round 3) Nitrate download retried in 3-year windows (1985-2026, with bisection on timeout). If it completes, nitrate (>10 mg/L) would be run with the same protocol and reported; if not, it stays out of the paper.
21. (2026-11-23, round 3) Nitrate abandoned. After a date-window retry (3-year windows, bisection on timeout), a single state-window request took 54 s to over 240 s (timeouts) and the first state had not finished after about an hour of six parallel workers. A national nitrate pull would take many hours, so nitrate is NOT in the paper. Evidence: this log entry and the download logs.
22. (2026-11-23, round 3) Third contaminant: fluoride (USGS Samples API, unit mg/L), chosen after nitrate failed because it is geogenic and widely modelled. Thresholds fixed before any fluoride run: 2 mg/L (US secondary standard) and 4 mg/L (US MCL); unit-size rule unchanged (>=100 wells, >=15 unsafe); 8 tuning states, or 4 if fewer than 17 states qualify (decided at the same count rule used for uranium). Same methods, tuning budget and statistics.
23. (2026-11-23, round 3) A controlled simulation on synthetic Gaussian random fields (correlation length 1-80 km) was added to test the clustering mechanism directly: `code/src/synthetic_mechanism.py`, run once, all results reported.
24. (2026-11-23, round 3) Fluoride: 48 of 49 states retrieved (single request for 33 states, date windows for 15); Kansas could not be retrieved in about 25 minutes and is excluded. Thresholds 2 and 4 mg/L fixed before any run (deviation 22).
25. (2026-11-23, round 3, before the fluoride runs) Fluoride runs use 3 seeds instead of 5 (the table has 150,299 wells, about three times the arsenic table; compute time). Base predictors only (no geology). Eligible states: 27 for 4 mg/L and 39 for 2 mg/L; 8 tuning states each. Everything else as in the main protocol.
