Result tables behind the Letter and Supporting Information (CSV). summary_* : enrichment at 5-30% of wells tested by method; statistics_* : paired tests with Holm correction; abf_* : adaptive Bayesian-mixture rule results; replay_* : replay of real sampling campaigns (including route length, time-respecting maps and larger batches); learner_*, robustness_*, checks_*, hierarchical_ABF_* : additional checks. Source data are public (USGS Samples API, USGS State Geologic Map Compilation, NASA POWER).
